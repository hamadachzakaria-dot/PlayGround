# انشر الآن — قائمة النشر النهائية (3 كتب، ~15 دقيقة)
الملفات في صفحة المعاينة → قسم 📚 (كلها verified 200).

## لكل كتاب (كرر 3 مرات)
1. `kdp.amazon.com` → Bookshelf → **+ Create → Paperback**.
2. **Details**: الصق Title + Subtitle + Author + Description من ملف `BOOKn_KDP_METADATA.md`.
   - Language: English | Age range: 4-8 (حيث متاح).
3. **AI-generated content?** → اختر **No** (رسومنا مرسومة برمجيًا أصلية، ليست AI).
4. **ISBN** → Free KDP ISBN.
5. **Categories**: اختر الفئتين من ملف Metadata.
6. **Keywords**: الصق السبع خانات.
7. **Upload interior** → ملف `Bookn_..._INTERIOR.pdf` → **Upload cover** → ملف `Bookn_..._COVER.pdf`.
8. **Launch Preview** → تصفح أول/وسط/آخر صفحات → لا أخطاء.
9. **Price**: **$9.99** (Amazon.com) — Expanded Distribution: اترك الافتراضي أول أسبوع.
10. **Approve/Publish** → يظهر خلال 24-72 ساعة.
